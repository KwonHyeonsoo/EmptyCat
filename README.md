# 🐾 Empty Cat

적들을 물리치고 꽃을 모으며 진열장에서 벗어나자!  
2D 횡스크롤 러닝 액션 게임 **Empty Cat** 입니다.

---

## 🧩 개요

- **장르**: 2D 횡스크롤 러닝 액션 (Side-scrolling Runner Action)
- **타겟 플랫폼**: PC (Windows)
- **플레이 타임**: 약 30분 예상
- **스테이지 수**: 총 10개 예정
- **컷신**: 오프닝 및 엔딩 컷신 포함

---

## 📖 스토리라인

진열장 안, 똑같이 생긴 유리 화병들이 늘어선 곳.  
그 속에 있는 한 고양이 화병은 스스로를 꾸며 사람들의 관심을 얻고자 합니다.  
꽃을 모아 진정한 자신만의 화병이 되기 위한 여정이 시작됩니다.  

우리의 고양이는 과연 사람들의 사랑을 받을 수 있을까요?
---

## 🎮 조작법

| 조작 | 동작 |
|------|------|
| `W` 또는 `↑` | 점프 |
| `S` 또는 `↓` | 아래 칸으로 내려가기 |
| 마우스 왼쪽 버튼, 'SPACE' | 파이어볼 / 워터볼 발사 |

---

## 📝 기타 정보

- 각 스테이지는 고유의 배경과 장애물, 적을 포함하고 있습니다.
- 감성적인 도트 그래픽과 연출 중심의 컷신이 매력 포인트입니다.
